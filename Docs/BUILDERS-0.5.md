## Rules that are not negotiable
- **Stored data.** Avoid new stored fields. If your lane truly needs one: CodingKeys case + tolerant reading + its writing line (`encodeIfPresent`) + the format-5 list in `SafetyTests.swift` + fill it in `testEveryStoredFieldIsReallyWritten` + say so in your report. Never raise the format again. What is only this device's business (a view's place, what was read from PARAGON, a switch) goes to `UserDefaults` / Application Support, never into the board.
- **Kinds.** Every `switch` over `ItemKind` must handle `.door`. A timeline and a "Who does what" board place their things themselves (`board.placesItself`): every new ordinary tool, menu line, paste and tidy command is OFF there.
- **Pictures.** A picture's file name may only ever be named inside Boards, Removed, SafetyCopies and Starters (devices still on 0.3 / 0.4 delete after 30 days any picture named elsewhere).
- **PARAGON.** Seedboard only ADDS to PARAGON (a new note, a new picture, lines appended to the waiting list `capture-outbox.jsonl`). It may READ PARAGON's notes. It never opens an existing PARAGON file for writing. Never try Send on his real notes: copy `~/Developer/AMS-PARA/Example Vault` to a scratch folder and use `-paragonFolder <that copy>` (DEBUG) with `-sendNow note|project|todos`.
- **Look.** Hand-drawn marks only (through `NewMark` / `AppMark` / `ControlMark`): no emoji, no SF Symbols, no stock icons, no glow or neon. Each part keeps its own colour (`Part.…`). The main button is full colour, never grey. Every page where something is changed has Cancel and Save (or Done); on the Mac Escape is Cancel. Compact: minimal padding, Apple's standard text sizes (`Txt.…`). Day and night both. Every new motion honours `Feel.moves`.
- **Words.** Everything the owner reads is plain English without computer talk ("sync", "file format", "cache", "JSON" never appear on screen). Follow the wording already in the app. The example person in samples is "Alex".
- **Turned down — never build or propose:** small pictures you can read (9), a mind map as a list (14), a PARAGON project as a board (21), widget (25), two windows (26), a board as a real file (27), words under the tool tiles, find inside a board, a note on an idea, big-board speed work.
- **Never move what he placed.** A redesign of a screen he knows needs his pick first (the lead asks him). Do not rearrange existing screens beyond what your lane says.

- Do not touch: `App/Sources/Guide.swift` (How it works / What's new), `Docs/SPEC.md`, `README.md`, version numbers, `Tools/release.sh`, and `project.yml` beyond what your lane names. The xcodeproj is generated and not in git.
